# Spotify Music Data Analysis – Track Popularity, Genre Trends & Audio Feature Insights

## Project Overview
This project focuses on analyzing Spotify music data to identify patterns and trends in track popularity, music genres, artists, albums and audio features using Python.

## Dataset Information
- Original records: 114,000
- Original columns: 21
- Final cleaned records: 113,549
- Final columns: 22

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Cleaning
- Removed unnecessary index columns.
- Handled missing values.
- Removed duplicate track-genre combinations.
- Validated audio feature ranges.
- Checked invalid and zero-duration records.
- Created duration-related columns for analysis.

## Exploratory Data Analysis
- Track popularity distribution.
- Genre-wise popularity comparison.
- Top artists and albums by average popularity.
- Audio feature analysis across 114 genres.
- Popularity vs energy analysis.
- Explicit vs non-explicit track comparison.
- Track duration vs popularity analysis.

## Key Findings
- Pop-film recorded the highest average genre popularity (59.28).
- Bad Bunny ranked first among artists with at least 20 track records, with an average popularity of 87.08.
- Un Verano Sin Ti recorded the highest average album popularity (90.14) among albums with at least 5 records.
- Death-metal showed the highest average energy (0.931).
- Classical showed the highest average acousticness (0.917).
- Medium-duration tracks (3–5 minutes) recorded the highest average popularity (34.76).

## Project Conclusion
The analysis provided insights into music popularity patterns, genre characteristics and audio feature distributions. This project strengthened my skills in Python-based data cleaning, exploratory data analysis, data visualization and insight generation.
